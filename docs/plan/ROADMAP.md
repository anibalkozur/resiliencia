# Roadmap

**Fase 1 — MVP (implementado en esta entrega):** Home, onboarding,
perfil, ejercicios, plantillas, retos, reto diario, entrenamiento,
calendario, racha, XP, niveles, logros, estadísticas básicas, offline.

**Fase 2:** amigos, grupos, retos grupales, rankings, temporadas, QR,
perfiles de Gym, Gym Dashboard básico.

**Fase 3:** Premium + billing, Gym Pro, promociones de gimnasios, retos
destacados, rankings patrocinados.

**Fase 4:** IA (recomendaciones, generación de retos), contenido premium,
desafíos patrocinados por marcas, eventos, integraciones.

**Fase 5:** cadenas de gimnasios (Enterprise), entrenadores, empresas,
wearables, marketplace, expansión internacional.
