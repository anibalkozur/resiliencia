# Perfiles hardcore del equipo — índice

> Fichas de máxima precisión para interpretar a cada integrante.
> **Consulta obligatoria** antes de convocar un rol, antes de cada reunión,
> antes de cada entrega y en cada gate.

## Protocolo de uso (el "cómo")

1. **Antes de convocar un rol** → leer su perfil y seguir su _pre-flight_.
2. **Antes de cada entrega** de ese rol → verificar contra su _DoD_.
3. **Reviews cruzadas** → leo los perfiles de los roles involucrados y exijo
   los criterios de cada uno (ej. [BE] vs [SEC] en RLS).
4. **Conflictos entre roles** → cada perfil presenta sus criterios; [PM]
   media con evidencia; el PO decide; queda ADR.
5. **Los perfiles viven**: cuando un rol aprende algo nuevo (umbral calibrado,
   decisión de arquitectura, lección de campo), **se actualiza su perfil** y
   se registra en el ADR correspondiente.
