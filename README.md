# ResiliencIA

Aplicación de retos de ejercicios con cámara verificada e IA. Monorepo pnpm.

## Estructura

```
apps/
  mobile/            App Expo (React Native + expo-router)
  web-b2b/           Panel web B2B (próximamente)
packages/
  design-tokens/     Tokens de marca del brand guide
supabase/            Migraciones SQL (próximamente)
```

## Comandos

```bash
pnpm install        # instala todo el workspace
pnpm -r typecheck   # chequeo de tipos
```
